## Toplantı 0.3.0

İlk GitHub dağıtımı ve uygulama içi güncelleme altyapısı.

- Menüden ve Ayarlar’dan yeni sürümleri kontrol etme.
- İmzalı uygulama paketleri ve imzalı sürüm bilgisi.
- Kayıt, kurtarma veya not hazırlama bitene kadar yeniden başlatmayı bekletme.
- Türkçe yerel transkript, kaynak bağlantılı özet ve ayrı mikrofon/sistem kayıtları korunur.

Apple Silicon Mac içindir. Yerel transkript macOS 26+, yerel özet desteklenen Mac’te Apple Intelligence gerektirir. İlk güncellenebilir sürüm bir kez Applications klasörüne kurulmalıdır. Sonraki sürümler uygulama içinden kurulabilir.

Bu paket Apple Developer ID ile imzalanmış veya Apple tarafından notarize edilmiş değildir; macOS ilk açılışta güvenlik uyarısı gösterebilir.
